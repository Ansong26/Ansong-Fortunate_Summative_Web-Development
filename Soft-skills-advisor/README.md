The Soft Skills Advisor is an interactive web application that helps incoming students reflect on their personal strengths and identify the soft skill they should develop further. The project uses HTML, CSS, and JavaScript, with all three technologies working together to create a single interactive application. The index.html file contains the four main views: the landing page, interactive quiz, results page, and contact/feedback page. The styles.css file controls the interface design, including cards, navigation, forms, buttons, responsive layouts, progress indicators, validation colours, and error messages. The script.js file controls the application's logic, including form validation, quiz generation, timer functionality, answer collection, category scoring, speed and streak multipliers, interactive media, DOM manipulation, and Canvas chart generation. The four assessment categories are Communication, Critical Thinking, Time Management, and Leadership.

To use the application, open index.html in a browser and complete the student profile on the landing page. The application checks the information as it is entered and displays validation messages directly below fields that contain errors. Once the profile is valid, select Start Assessment and complete the eight-question quiz. The questions are generated dynamically using JavaScript, while the progress indicator and countdown timer update automatically. Some questions include interactive media such as image hotspots or video-based scenarios. After the quiz is submitted, the scoring engine calculates the student's performance across the four soft-skill categories and displays the strongest area, descriptive feedback, and suggested next steps. A Canvas 2D graph visually represents the student's category scores.

For deployment, upload the project files to a public GitHub repository and activate GitHub Pages so that the application can be accessed through a live web link. The application does not depend on external JavaScript libraries, making it suitable for demonstrating core frontend development skills. The most important code sections to understand are the state object, the questions array, showView() for navigation, validateForm() for real-time validation, startQuiz() for beginning the assessment, startTimer() for countdown functionality, renderQuestion() for dynamic quiz generation, submitQuiz() for scoring, and drawChart() for Canvas rendering. These functions demonstrate how HTML, CSS, and JavaScript work together to create an interactive student-support tool.
