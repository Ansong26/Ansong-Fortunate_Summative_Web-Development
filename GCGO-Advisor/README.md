The GCGO Advisor is an interactive learning-journey application designed to help incoming students connect their interests, strengths, and goals with four areas of Global Citizenship and Goals (GCGO): Education, Health, Climate Change, and Women Empowerment. The application is developed with HTML, CSS, and JavaScript. The index.html file creates the semantic structure and contains the landing, quiz, results, and contact/feedback views. The styles.css file provides the visual design and responsive layout, while also creating the visual states for valid and invalid form fields. The script.js file is responsible for the interactive functionality, including regular-expression validation, dynamic question rendering, progress tracking, countdown timing, answer recording, category scoring, speed and streak bonuses, interactive media, dynamic DOM updates, and the Canvas 2D results graph.

To use the website, open index.html in a browser and enter the required student information on the landing page. The application validates the information in real time and provides inline error messages instead of browser alert pop-ups. After selecting Start Assessment, the student answers the eight quiz questions while the progress indicator and countdown timer track their progress. The application records each response and uses the scoring engine to determine which GCGO area most closely matches the student's interests and strengths. Once the assessment is complete, the Results page provides a recommended GCGO area, an explanation of the result, suggested next steps, and a Canvas-generated chart showing the student's performance across Education, Health, Climate Change, and Women Empowerment. The Contact & Feedback page allows users to provide additional information or feedback.

The project can be hosted on GitHub Pages by placing index.html, styles.css, and script.js in a public repository and enabling Pages through the repository settings. The project uses standard frontend technologies and does not require external frameworks or Canvas libraries. It demonstrates important concepts such as semantic HTML, CSS responsive design, JavaScript functions and objects, event listeners, regular expressions, dynamic DOM manipulation, HTML5 multimedia, countdown timers using setInterval() and clearInterval(), JavaScript scoring algorithms, and Canvas 2D graphics. For a code walkthrough, the main sections to explain are state, questions, showView(), validateForm(), startQuiz(), startTimer(), renderQuestion(), selectAnswer(), submitQuiz(), drawChart(), and submitContact().
